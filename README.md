# Databricks Sales Data Pipeline

## Project Overview

This project demonstrates an end-to-end Sales Data Pipeline built using Databricks and the Medallion Architecture.

### Architecture

Bronze → Silver → Gold

### Technologies

- Databricks
- PySpark
- Spark SQL
- Delta Lake
- Unity Catalog

### Features Implemented

- CSV Data Ingestion
- Bronze Delta Tables
- Silver Transformations
- Revenue Calculation
- Null Handling
- Deduplication
- Window Functions
- Gold Aggregations
- SQL Analytics
- Delta Time Travel
- Partitioning
- OPTIMIZE
- VACUUM

### Gold Tables

- gold_region_sales
- gold_product_sales
- gold_customer_sales
- gold_monthly_sales
